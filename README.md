# Сервис отправки сообщений в мессенджер WhatsApp

Сервис для отправки сообщений в приложение WhatsApp.

## Запуск проекта

### Версия node для установки зависимостей v24.21.0

1. Клонировать репозиторий

```bash
git clone https://github.com/NVinox/green-chat.git
```

2. Установить зависимости

```bash
npm install
```

3. Объявить переменные окружения

```bash
cp .env.example .env.development
```

4. Запустить проект

```bash
npm run dev
```
